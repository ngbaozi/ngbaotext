# Music Source Scripts

Standalone JavaScript music source scripts. Import any `.js` file by URL, or download it for local import.

## Import

- Raw: `https://raw.githubusercontent.com/ngbaozi/music-source-scripts/main/LXYY1.js`
- CDN: `https://cdn.jsdelivr.net/gh/ngbaozi/music-source-scripts@main/LXYY1.js`
- Clone: `https://github.com/ngbaozi/music-source-scripts.git`

Replace `LXYY1.js` with any filename from the table below.
